Politique de confidentialité

Application : eToro Monitoring Backup (page d'accueil). Outil personnel, non commercial, dont l'auteur est le seul utilisateur.

1. Données Google auxquelles l'application accède

L'application demande uniquement la portée Google Drive https://www.googleapis.com/auth/drive.file. Cette portée lui permet de créer des fichiers et des dossiers dans le Google Drive de l'utilisateur qui l'a autorisée, et de lire ou de modifier seulement les fichiers qu'elle a elle-même créés. Elle n'accède à aucun autre fichier du Drive, ni au profil, aux contacts, au courrier ou à tout autre service Google.

2. Utilisation des données

Les données Google sont utilisées exclusivement pour déposer des archives de sauvegarde dans le Drive de l'utilisateur, en vérifier l'intégrité après transfert et en dresser l'inventaire. Les archives sont chiffrées avant l'envoi ; leur contenu n'est pas lisible par Google ni par un tiers.

3. Stockage

Les fichiers sont stockés uniquement dans le Google Drive de l'utilisateur. Le jeton d'autorisation OAuth est conservé par l'utilisateur dans ses propres outils (configuration locale et coffre de secrets d'automatisation) et n'est transmis à aucun service tiers.

4. Partage

Aucune donnée Google n'est partagée, vendue, transférée ni communiquée à qui que ce soit. L'application n'utilise aucun service d'analyse, de publicité ni de suivi.

5. Conservation et suppression

Les archives restent dans le Drive de l'utilisateur jusqu'à ce qu'il les supprime lui-même. L'accès de l'application peut être révoqué à tout moment depuis la page Applications tierces ayant accès à votre compte ; la révocation rend immédiatement le jeton inutilisable.

6. Engagement

L'utilisation des données obtenues via les API Google respecte la Google API Services User Data Policy, y compris les exigences d'utilisation limitée (Limited Use).

English summary. eToro Monitoring Backup requests only the Google Drive drive.file scope. It creates encrypted backup archives in the authorizing user's own Drive and can read or modify only the files it created. No Google user data is shared, sold or transferred to anyone; no analytics or tracking is used. Files stay in the user's Drive until the user deletes them; access can be revoked at any time at myaccount.google.com/permissions. Use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements.
