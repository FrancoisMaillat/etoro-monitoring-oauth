Politique de confidentialité

Application : eToro Monitoring Backup, outil personnel de sauvegarde chiffrée vers Google Drive. Un seul utilisateur : son auteur. Cette politique décrit l'usage fait des données Google auxquelles l'application accède.

1. Données Google auxquelles l'application accède

L'application demande uniquement la portée OAuth https://www.googleapis.com/auth/drive.file. Cette portée l'autorise à créer des fichiers dans le Google Drive de l'utilisateur et à lire, vérifier ou lister les seuls fichiers qu'elle a elle-même créés. Elle n'a accès à aucun autre fichier, dossier ou information du compte Google.

2. Utilisation des données

  • Déposer des archives de sauvegarde, chiffrées avant l'envoi, dans un dossier dédié du Drive de l'utilisateur.
  • Relire ces archives après le dépôt pour en vérifier l'intégrité (taille, empreinte).
  • Lister ce dossier pour établir un inventaire des sauvegardes et consulter l'espace disponible.

Aucune autre utilisation. Les données ne servent ni à de la publicité, ni à du profilage, ni à l'entraînement de modèles.

3. Stockage

Les archives sont stockées uniquement dans le Google Drive de l'utilisateur. Le jeton d'accès OAuth est conservé dans un coffre de secrets chiffré, sous le contrôle exclusif de l'utilisateur, et n'est jamais écrit dans un journal, un fichier public ou une archive.

4. Partage et transfert

Aucune donnée n'est partagée, vendue, louée ni transmise à un tiers, à quelque fin que ce soit. L'application n'utilise aucun service d'analyse d'audience ni aucun traceur.

5. Conservation et suppression

Les archives restent dans le Drive de l'utilisateur jusqu'à ce qu'il les supprime lui-même. L'utilisateur peut à tout moment retirer l'accès de l'application depuis myaccount.google.com/permissions ; l'application perd alors immédiatement toute capacité d'accès.

6. Conformité

L'utilisation des informations reçues des API Google respecte la Google API Services User Data Policy, y compris les exigences d'usage limité (Limited Use).

7. Contact

Pour toute question : FrancoisMaillat sur GitHub.

English summary: This personal application requests only the drive.file scope and can therefore only create, list and verify files it created itself in the user's own Google Drive. Data is used solely to store and verify encrypted backup archives. Nothing is shared, sold or transferred to third parties; no analytics or trackers are used. Access can be revoked at any time at myaccount.google.com/permissions. Use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements.
